# TFG-Chess

Este repositorio contiene el código fuente y los recursos asociados al Trabajo de Fin de Grado (TFG) titulado **"TFG-Chess"**. El proyecto tiene como objetivo desarrollar una plataforma para analizar, estudiar y jugar al ajedrez, integrando funcionalidades avanzadas relacionadas con el aprendizaje automático y análisis de partidas.

## Contenido del Repositorio

- **src/**: Código fuente del proyecto.
- **data/**: Conjuntos de datos utilizados para entrenar modelos o realizar análisis de partidas.
- **notebooks/**: Cuadernos Jupyter para exploración de datos, visualización y experimentación.
- **models/**: Modelos entrenados y scripts relacionados con el aprendizaje automático.
- **docs/**: Documentación adicional y recursos relacionados con el proyecto.

## Requisitos Previos

Asegúrate de tener instalados los siguientes elementos antes de ejecutar el proyecto:

- Python 3.8 o superior
- pip (gestor de paquetes de Python)

### Dependencias

Puedes instalar las dependencias del proyecto ejecutando:

```bash
pip install -r requirements.txt
```

## Cómo Usar Este Proyecto

1. Clona este repositorio:
   ```bash
   git clone https://github.com/OriolCamps33/TFG-Chess.git
   cd TFG-Chess
   ```
2. Instala las dependencias (ver sección anterior).
3. Ejecuta los scripts o experimentos desde el directorio `src/` o explora los cuadernos en `notebooks/`.
